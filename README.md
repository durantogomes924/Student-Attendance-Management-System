# Attendance Sheet (Java)

A Java-based attendance sheet application that helps teachers and administrators
record, manage, and track student attendance quickly and accurately.

## 📋 Features

- Add and manage student records
- Mark daily attendance (Present / Absent / Late)
- View attendance history per student or per date
- Calculate attendance percentages
- Simple and easy-to-use interface

## 🛠️ Tech Stack

- **Language:** Java
- **Concepts used:** Object-Oriented Programming, Collections, File I/O
- *(Optional)* GUI: Java Swing / JavaFX — update if applicable
